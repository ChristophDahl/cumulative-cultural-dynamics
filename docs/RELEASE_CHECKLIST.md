# Release checklist

Before making the repository public:

- [ ] Run `smoke_test` locally in MATLAB.
- [ ] Run the complete pipeline, or confirm that the archived result files were generated by the final public code.
- [ ] Run `validate_outputs`.
- [ ] Compare regenerated manuscript figures with the submitted figures.
- [ ] Confirm that the manuscript's code/data availability statement points to the final repository or DOI.
- [ ] Replace any provisional manuscript citation details after publication.
- [ ] Create a GitHub release tag, preferably `v1.0.0`.
- [ ] If using Zenodo, enable GitHub integration and archive that release.
- [ ] Add the resulting software DOI to `README.md`, `CITATION.cff`, and `CITATION.bib` in a subsequent release if appropriate.
- [ ] Do not commit large local result files unless they are intentionally part of the release.
