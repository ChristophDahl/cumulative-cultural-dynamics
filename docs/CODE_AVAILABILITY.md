# Suggested code-availability statement

Once the GitHub repository and/or archival DOI is public, the manuscript can use a statement such as:

> All source code required to reproduce the simulations, analyses, numerical summaries, and figures is publicly available at [REPOSITORY/DOI]. The repository includes fixed random-seed construction, the complete MATLAB analysis pipeline, and documentation linking each analysis to the corresponding manuscript outputs.

If seed-level result files are deposited separately because of repository size, add their archive DOI to the same statement.
