# Reproducibility guide

## 1. Configure the repository

Start MATLAB in the repository root and run:

```matlab
setup_project
```

This adds the `matlab/` folder to the MATLAB path and creates the output directories if required. No absolute local drive paths are used.

## 2. Check the software installation

```matlab
smoke_test
```

The smoke test reduces population size and generation count and runs both public single-simulation engines. It checks execution and basic output bounds only; it is not a manuscript-result test.

## 3. Full reproduction

The one-command workflow is:

```matlab
run_reproduction
```

It executes the analysis families in the following order.

### Baseline grid

```matlab
run_baseline_grid
summarise_baseline_grid
```

Output:

`results/baseline/baseline_grid_results.mat`

This analysis supplies Fig. 1, Fig. 2, and Fig. S1.

### Quality dynamics

```matlab
run_quality_dynamics
```

Output:

`results/mechanism_controls/quality_dynamics_results.mat`

This representative analysis supplies the baseline quality trajectories used in Fig. 3A–B. It reproduces the matched seed stream used for those trajectories at `mu = 0.15` and `phi = 0.98` without rerunning the full control grid.

### Mechanism controls

```matlab
run_mechanism_controls
```

Output:

`results/mechanism_controls/mechanism_controls_results.mat`

This analysis contains the baseline, random-demonstrator, repair-capable random-copy-error, and greedy-acceptance conditions, including both functional and structural ancestry metrics.

### Discrimination sensitivity

```matlab
run_discrimination_sensitivity
```

Output:

`results/discrimination_sensitivity/discrimination_sensitivity_results.mat`

The success-bias sweep varies `beta = [0 1 2 5 10]` with baseline evaluation strength. The evaluation sweep varies `gamma = [2 5 10 20 Inf]` with baseline success bias. Both use the representative favourable condition `mu = 0.15`, `phi = 0.98` and both scaffolding levels.

### Graded task landscapes

```matlab
run_graded_task_landscapes
```

Output:

`results/graded_task_landscapes/graded_task_landscapes_results.mat`

Opacity is varied over `[0 0.25 0.50 0.75 0.90]`; sequence dependence over `[0 0.25 0.50 0.75 1.00]`. The analysis retains task-specific payoff, common-scale component/prefix measures, exact-target fraction, and both lineage-depth measures.

## 4. Export numerical summaries

```matlab
summarise_extended_analyses
```

CSV files are written directly into the corresponding analysis-family folders under `results/`. The baseline CSV files are generated by `summarise_baseline_grid`; the mechanism-control, discrimination-sensitivity, and graded-landscape CSV files are generated by `summarise_extended_analyses`.

## 5. Regenerate manuscript figures

```matlab
run_manuscript_figures
```

Figures are written to `figures/manuscript/` in PNG, PDF, and MATLAB FIG formats.

## 6. Validate the completed run

```matlab
validate_outputs
```

This checks the expected `.mat` and `.csv` result files, all seven manuscript figure stems in all three output formats, and the core baseline parameter settings.

## Independent stochastic analysis families

The manuscript analyses were generated in separate simulation families using the same core model parameters but different deterministic seed constructions. Small differences in absolute means across nominally identical conditions in different result files therefore reflect independent stochastic realisations. Interpret comparisons within their corresponding matched analysis family.

## Random-number matching

Within mechanism and sensitivity comparisons, the code deliberately aligns seeds across the contrasted conditions. In the extended simulator, a uniform acceptance variate is consumed on every update, including deterministic greedy controls, to keep matched random-number consumption aligned.

## Output retention

The `results/` directory is intentionally not ignored by Git. This allows the final reviewer-facing CSV files and, where file size permits, the canonical `.mat` result files to be committed with the release. If any `.mat` file becomes too large for the repository, retain its CSV summaries on GitHub and archive the full `.mat` output with the DOI-backed release.

## Result organisation

`run_reproduction` writes each analysis family to its own subfolder under `results/`: `baseline/`, `mechanism_controls/`, `discrimination_sensitivity/`, and `graded_task_landscapes/`. CSV summaries are generated automatically from the saved MATLAB result structures during step 6 of the pipeline.
